TYPE

Problem

메인 페이지가 AI로 만든 것 같아요

기존 화면을 살펴보고, 개선할 부분부터 정리해볼게요.

  1. 01

    정형화된 화면 구성

    반복되는 카드와 섹션 구성으로 서비스만의 개성이 부족했습니다.

  2. 02

    불명확한 정보 우선순위

    검색과 추천 콘텐츠가 함께 강조되어 사용자의 핵심 행동이 명확하지 않았습니다.

  3. 03

    약한 브랜드 인상

    가격 비교와 호텔 탐색이라는 서비스의 특징이 화면에서 충분히 드러나지 않았습니다.

무엇을 바꿀 것인가

  1. 01

    정보 구조 재정리

    핵심 정보와 추천 콘텐츠의 우선순위를 명확하게 구분

  2. 02

    검색 중심 탐색 강화

    검색을 핵심 행동으로 배치해 숙소 탐색 흐름 개선

  3. 03

    브랜드 인상 강화

    블루 중심의 일관된 비주얼 톤으로 서비스 개성 강화

Point

한 화면에서 결정하는 “경험”

KEY SCREENS

01

Main Visual & Search

여행 비주얼 아래 검색창을 겹쳐 배치했습니다.여행지 날짜 투숙객 입력을 한곳에 모았습니다.

02

특가 호텔

숙소 이미지와 할인율·가격을 함께 표시했습니다.좌우 슬라이더로 숙소를 비교할 수 있습니다.

03

HOT 여행지

국내·해외 탭과 도시 목록을 구분했습니다.선택한 여행지의 추천 콘텐츠를 보여줍니다.

04

평점 높은 숙소

지역 필터를 숙소 목록 위에 배치했습니다.이미지 가격 평점을 같은 구조로 비교합니다.

05

제휴 문의 CTA

숙소 탐색 다음에 제휴 문의 CTA를 배치했습니다.탐색과 제휴 문의의 목적을 구분했습니다.
